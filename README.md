# Metro Run 3D

A lightweight browser-based 3D-style bus simulation game. Drive through a stylized city route, pick up passengers, deliver them, and manage your fuel.

## Play

Open `index.html` in a browser.

- **A/D** or **Left/Right**: steer
- **W/S** or **Up/Down**: accelerate/brake
- **Space**: brake

Complete every stop before running out of fuel.
